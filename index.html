03 Toolbox

Toolbox

Python

YOLO 학습, OpenCV 영상처리, ROI/IoU 판정 로직, 데이터 정제와 시각화 작업에 사용했습니다.

Embedded

STM32, Raspberry Pi, UART, GPIO를 활용해 센서 입력과 제어 명령이 실제 장비에서 동작하도록 구성했습니다.
